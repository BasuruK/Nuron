## Top mapping implications

- **`nuron-ai` is a system-boundary introduction, not a feature.** It changes the deployment topology and the ownership wording throughout §4 / §5.3 / §5.4 / §7, but introduces no new acceptance criteria. Architecture should treat it as a third container; this PRD does not specify its transport protocol, framework, or scaling axis beyond the comment's wording.
- **Retrieval pipeline is now named, not generic.** FR-8 moves from "vector + structural + BM25" with weighted-score fusion to "HNSW + BM25 → RRF → LLMRerank, with structural graph expansion / lineage traversal as a fourth named mode." Architecture's remaining RAG work is parameter pin (RRF `k`, HNSW `M`/`ef*`, BM25 tokenizer, LLMRerank model) — the algorithm names are now locked.
- **Two `[ASSUMPTION]` tags retire.** FR-1's UTF-8 bullet and FR-6's contradicted-evidence bullet are now confirmed. §10 Assumptions Index loses both corresponding entries. No new assumptions are added by this round.
- **FR-11 deferral is the largest single change.** It touches 10 sections but the changes are coordinated: identifier preserved, downstream FR-12…FR-17 untouched, Default Agent (FR-10) unaffected, UJ-3 and SM-4 relocated to deferred-to-v2 framing. This is a clean separation of v1 (ingest → compile → curate → query, with Default Agent as the only runtime agent) from v2 (Agent Templates library).
- **No contradictions between the six comments.** Comments 2 and 5 are complementary anchors for the same retrieval-path change; comment 1 is orthogonal to all others; comments 3 and 4 are pure confirmation; comment 6 is a self-contained rescope.
